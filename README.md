# SG90 舵机控制 - ESP32-S3 (ESP-IDF)

## 项目说明
这是一个基于 ESP-IDF v6.0、使用 LEDC PWM 驱动 SG90 舵机的标准嵌入式项目，核心是通过脉冲宽度控制舵机角度（0°~180°）。

## 硬件接线

| SG90 舵机 | ESP32-S3 | 说明 |
|-----------|----------|------|
| VCC (红色) | 5V | 可使用外部 5V 电源，需共地 |
| GND (黑色/棕色) | GND | 必须共地 |
| SIG (黄色/橙色) | GPIO2 | PWM 信号线 |

**注意：**
- SG90 工作电流峰值可达 500mA，建议使用外部 5V 电源供电
- 如果使用 ESP32-S3 开发板的 5V 引脚，确保开发板能提供足够电流
- **必须共地**：外部电源的 GND 需与 ESP32-S3 的 GND 连接

## 环境要求

- ESP-IDF v5.0 或更高版本
- ESP32-S3 开发板
- USB 数据线
- SG90 舵机

## 编译和烧录

```bash
# 设置目标芯片为 ESP32-S3
idf.py set-target esp32s3

# 编译项目
idf.py build

# 烧录到设备（替换 /dev/ttyUSB0 为你的串口）
idf.py -p /dev/ttyUSB0 flash

# 监视串口输出
idf.py -p /dev/ttyUSB0 monitor
```

## 测试方法

1. 按照接线图连接硬件
2. 编译并烧录程序到 ESP32-S3
3. 打开串口监视器，观察日志输出
4. 舵机将自动执行以下测试：
   - 从 0° 转动到 180°（平滑扫描）
   - 在几个关键角度停留验证（0°, 45°, 90°, 135°, 180°）
   - 循环往复运动

## 角度精度说明

SG90 舵机的脉宽参数：
- 0°: 约 0.5ms 脉宽
- 90°: 约 1.5ms 脉宽  
- 180°: 约 2.5ms 脉宽

由于不同舵机个体差异，实际角度可能需要微调脉宽参数。

## 故障排除

1. **舵机不转动**
   - 检查电源连接是否正确
   - 确认共地连接
   - 检查 GPIO 引脚是否正确

2. **舵机抖动**
   - 电源电流不足，尝试使用外部电源
   - 检查信号线连接是否稳固

3. **角度不准确**
   - 调整 `SERVO_MIN_US` 和 `SERVO_MAX_US` 参数
   - 不同品牌舵机脉宽范围可能不同
