# 在终端中使用ESP-IDF
## 第一部分·安装ESP-IDF
1. 下载安装器

    打开网站`https://dl.espressif.cn/dl/eim/`，按需下载对应版本的installer，设置好安装路径并完成安装
    我安装的版本的是`v6.0`
2. 运行环境激活脚本

    在终端里进入安装目录，我这里安装在`D:\.espressif\v6.0\esp-idf`
    依次运行以下三条命令
    ```
    cd D:\.espressif\v6.0\esp-idf
    install.bat esp32s3
    export.bat
    ```
    注意，要cd安装目录下的\esp-idf文件夹
    （跨盘cd要加用`cd /d`来用）


    正确完成此步骤可以在终端里看到
    ```
    Done! You can now compile ESP-IDF projects.
    Go to the project directory and run:

    idf.py build
    ```
    不要关闭这个终端，之后的命令都需要在这个终端上运行，且每次关闭后都要重新运行以上三条命令
3. 验证安装成功
    以安装在`D:\.espressif\v6.0\esp-idf`为例
    ```
    D:\.espressif\v6.0\esp-idf>echo %IDF_PATH%
    D:\.espressif\v6.0\esp-idf

    D:\.espressif\v6.0\esp-idf>idf.py --version
    ESP-IDF v6.0
    ```
## 第二部分·使用ESP-IDF编译和烧录
在**安装好ESP-IDF的情况下**使用

1. 
    在终端里进入安装目录
    依次运行以下2条命令
    ```
    cd D:\.espressif\v6.0\esp-idf
    export.bat
    ```
    （跨盘cd要加用`cd /d`来用）
1. 进入项目目录
    
    在先前的终端中cd进项目目录
    以项目目录为`E:\ESP-IDF\-esp32idf-main`为例
    ```
    cd /d E:\ESP-IDF\-esp32idf-main
    ```
    （跨盘cd要加用`cd /d`来用）

    然后就可以正常执行命令了

5. 使用`idf.py`命令设置芯片

    设置目标芯片为`ESP32-S3`，按需改为其他芯片
    ```
    idf.py set-target esp32s3
    ```
    成功执行以上命令后可以看到出现
    ```
    <一些信息，此处忽略>
    -- Configuring done (87.1s)
    -- Generating done (105.1s)
    -- Build files have been written to: E:/ESP-IDF/-esp32idf-main/build
    ```
5. 使用`idf.py build`命令编译代码

    （此步需要**较长时间**且容易遇到因为**版本不兼容**导致的报错）

    此命令将代码编译成可直接烧录到芯片内的**二进制固件**文件（`elf` `bin`等）
    ```
    idf.py build
    ```
    成功编译后可以看到
    ```
    <一些信息，此处忽略>
    -- Configuring done (120.2s)
    -- Generating done (162.2s)
    -- Build files have been written to: E:/ESP-IDF/-esp32idf-main/build
    <一些信息，此处忽略>
    Project build complete. To flash, run:
    idf.py flash
    <一些信息，此处忽略>
    ```
5. 使用`idf.py flash`命令烧录

    此命令将编译好的固件通过`COM9`串口烧录到目标芯片上
    在设备管理器中查看实际的串口
    ```
    idf.py -p COM9 -b 115200 flash
    ```
    其中
    `-p COM9`设置串口为COM9，`-b 115200`设置波特率为115200

    注意烧录一旦完成，程序就会运行
    ```
    烧录完成 → 开发板自动重启 → 程序立刻开始跑
    （断电则停跑，芯片断电后程序不会消失，一经上电继续从头跑程序，除非烧录新的程序覆盖掉原来程序）
    ```
6. 打开串口监视器查看芯片运行日志

    需要在命令中指定串口
    ```
    idf.py -p COM9 monitor
    ```
## 第三部分·ISSUE
### ①烧录完成后如何停止程序运行？
拔掉 USB 线→ **立刻断电 → 程序停止**

### ②如何在不重新烧录的情况下重启程序？
按开发板上的 **RESET 键**→ 程序会**重启**

### ③烧录完成后如何暂停运行？
**按住 BOOT 键不放**进入烧录模式→ 芯片会**停止执行当前程序**→ 舵机立刻不动，松开 BOOT 才会继续跑。

### ④如何清除原来的编译结果？
使用命令
```
idf.py fullclean
```
